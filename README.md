# 客語桌遊開發案

[開啟四縣腔語音網站](https://englishwang6.github.io/hakka-game-audio/)

- 60 段情境、20 段道具、6 段咒語。
- 四縣腔女聲：`hak-xi-TW-vs2-F01`。
- 語音來源：[客家委員會臺灣客語語音資料庫](https://speech.hakka.gov.tw/TTS/Synthesis)。
- 文本由本案編製；AI 合成音檔尚待顧問聽校。
- 更新時間：2026-09-19T18:15:39+08:00。
